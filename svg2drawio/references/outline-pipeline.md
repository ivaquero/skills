# 轮廓化 SVG 的重建工序

适用于 cairo/Pango 从 PDF 导出的图：**没有 `<text>`**，每段文字都是
`<use xlink:href="#glyph-…">` 引用的矢量字形。

判据（`rebuild.py --probe` 一次给出）：`<text>` 为 0、`glyph-` 定义上千、
图标尺上万个 `multi-subpath` 描边。实测样本：
2526×4167 的世系图，13994 个 `<use>`、5751 个字形、101 个字体子集、
8142 个 path（1233 填充 / 6909 仅描边，其中 5651 个是多子路径）、274 个虚线。

`svg2drawio.py` 在这种输入上只会把每块图形内嵌成图片，文字一条都留不下，
批量跑完也看不出错。所以这条工序必须单独走。

## 为什么值得重建，而不是整图内嵌

整图内嵌是像素级保真，但交付物等于一张截图：不能改字、不能连线、不能重排版。
重建的代价是字形识别（一次性、可复核），换来的是 393 个框、1210 条连线、
1297 行文字全部是原生对象。**判据是这幅图以后要不要改**；只归档就内嵌。

## 阶段 1 反推字形表

产物是一张 `glyph-id → 字符` 的 TSV（`assets/outline-glyphs.tsv` 是格式样板）。
这一步需要栅格化与距离变换，只能用 numpy / Pillow / scipy，所以**不进本包的
`scripts/`**（包内脚本一律标准库，否则换机器就跑不起来）。算法与参数照抄即可：

1. **提取轮廓**：`<defs>` 下 id 以 `glyph-` 开头的 `<g>`，取其所有 `path` 的
   `d`。注意 cairo 多套一层匿名 `<g>`，只读 `<defs>` 的直接子节点会得到 0 个字形。
2. **栅格化**：每个字形按 bbox 归一化后放进 64×64 单元，**居中放置**。
   不居中是本工序最贵的一个坑：`r` 被判成 `P`、`i` 被判成 `l`，
   而且错得很有规律、很难靠肉眼看出来。居中后 chamfer 距离均值从 0.58 降到 0.53。
3. **两级比对**：先用 IoU 粗筛出 top-40 候选（全量 5349×680 打分会直接吃光内存），
   再对候选算 chamfer 距离（`distance_transform_edt` + `binary_erosion` 取边缘）。
4. **软惩罚**：字高比、长宽比、前进宽度（advance）三项加权。
   advance 不必猜：相邻两个 `<use>` 的 `x` 之差就是 advance，
   除以参考字体的 `getlength(ch)/em` 即得该子集的 em。
5. **字库覆盖**：Arial 四体 + Times New Roman 四体。缺衬线体会把
   `Name of the Royal Family` 读成 `Naœc…`；缺西里尔/希腊会丢
   `Александра`、`Ανδρέας`。
6. **同形字归一**：西里尔 `АВЕКМНОРСТХ` 与拉丁 `ABEKMHOPCTX` 字形相同。
   按「单词里出现了西里尔/希腊独占字符」判语言，再整体映射，否则
   `Catherine` 里会混进一个西里尔 `е`，复制搜索全失效。

这一步的输出必须人工抽查：`Dòmhnall I`、`Alfred the Great`、`Земовит`、
`Ανδρέας` 这类跨字符集的样本过一遍，再抽 20 行看有没有残留的 `?` 和连字幻觉。

## 阶段 2 重建结构

`rebuild.py` 的判定阈值都是实测校准的，改之前先看后果：

| 源图形 | 判定 | 产出 |
| --- | --- | --- |
| 填充路径，bbox < 12×12 | 箭头 | 记 `tip = 第一个点`，只作为标记，不单独成 cell |
| 填充路径，`fill-opacity < 0.3` | 阴影 | 贴到最近的框上，`shadow=1` |
| 填充路径，其余 | 色块框 | `rounded=1` + `absoluteArcSize=1`，圆角按顶边直线段量 |
| 仅描边的闭合路径，4 个 `C` + 1 个 `Z`，w>18 h>10 | 卡片边框 | 也是框，`fillColor=none` |
| 仅描边，其余 | 连线 | 按子路径拆开，再按线段建图合并 |

## 阶段 3 陷阱表

每一条都实际踩过，且都**静默**出错：XML 合法、能打开、图不对。

### 3.1 一个 `d` 里有多条不相连的线

cairo 把若干不相连的线写进同一个 `d`（本样本 5651 处）。不按子路径拆开，
就得到一条横跨全图的折线，中间还带瞬移。

判据：`d.count("M") > 1`。

### 3.2 「总线式」连线会被虚线出卖

一条线画到框边再原路折返（分叉），在 PDF 里是一笔。按「一条描边 = 一条连线」
合并，就会得到一条把同一段几何走两遍的折线：

- 实线：看不出来；
- 虚线：两遍的相位不同，交错后**糊成实线**。

本样本 274 个虚线路径，第一版全部渲染成实线。改成「线段级建图 + 边不相交
路径分解」后，折返变成普通分叉，虚线恢复正常（成图 159 条虚线边）。

同一条规则的第二个坑：分解时**只有交叉点才做方向判断**。度数 2 的点是拐角，
沿它走是唯一选择；在这里也套「方向点积 > 0.93」会把每个 90° 直角断开，
边数直接翻倍（实测 1210 → 2404）。

### 3.3 `edge="1"` 不是可选的

带 `source`/`target`、带 `sourcePoint`/`targetPoint`、带 `<Array>`，
但少了 `edge="1"` 属性：draw.io 不报警，**整条线一条都不画**。
这条在写包装版脚本时又中了一次，症状是页面只剩框和文字。

### 3.4 一个中间点也必须进 `<Array>`

判 `if len(inner) > 1` 就会漏掉只有一个拐点的折线；draw.io 把它拉成
source→target 的直线，页面上出现大量横穿全图的斜线。

### 3.5 文档顺序就是图层顺序

先连线、再色块、最后文字。反过来，0.7px 的细线会从文字中间穿过，
读起来像删除线——而且只在放大后才看得出来。

### 3.6 箭头尖端是路径的**第一个点**

cairo 的三角形从尖端开始写。取「离质心最远的点」会落在底边中点，
于是每个箭头都指向反方向。匹配条件是尖端距离 < 4.5px 且
「尖端 − 质心」与线末端方向点积 ≥ 0.3，命中后从池子里删掉（一个箭头只服务一条线）。

早先还额外要求「端点在框上」才肯认箭头，结果悬空端的箭头全丢；
方向判据本身已经足够严格，不必再加这条。

### 3.7 draw.io 默认给每条边画经典箭头

不显式写 `endArrow=none;startArrow=none`，每条普通连线末端都会多出一个三角。

### 3.8 空白字形必须当空格

空字形（空格）的 bbox 是一个点，跟任何字符的形似度都很高，
于是句点经常赢——`3 generations skipped` 变成 `3.generations skipped`。
规则：字形轮廓 bbox 小于 0.05px 一律输出空格，**不看匹配分数**。
`assets/outline-sample.svg` 的 `glyph-0-4` 就是为这条规则准备的：表里故意写成
`.`，转换后必须是空格。

### 3.9 圆角按「顶边直线段的起点」量

`pts[0].x - bbox.left` 不是圆角，是「路径起点到左边界的距离」；
从左侧起笔的气泡会被叠加大圆角。正确做法：在 `y == bbox.top` 和
`y == bbox.bottom` 上找直线段，取最小内缩量。

### 3.10 半透明描边要混到白底上

draw.io 的 cell 没有线条 alpha。直接丢掉 0.15 的不透明度，阴影光晕和浅色表格线
就没了；直接保留成黑色，它们变成硬网格线。折中：按 alpha 与白底混色，
颜色略深但结构在。

同一张卡片常被画两遍（一圈 0.2 的光晕 + 一条 0.9 的边框），
去重时**按不透明度从高到低保留**，否则留下的是光晕。

### 3.11 单行标签要 `whiteSpace=nowrap`

框内单行文字一旦允许换行，`3 generations skipped` 会断成两行；
多行标签才用 `wrap`（`<br>` 连接）。

### 3.12 `arcSize` 要配 `absoluteArcSize=1`

否则 arcSize 被当成「短边的百分比」，所有卡片都变成胶囊形。

### 3.13 虚线的长度单位是**线宽**

`dashPattern` 会乘以 `strokeWidth`（同一 pattern 在 0.7 / 1.0 / 2.0 三种线宽下
导出对比过）。SVG 的 `stroke-dasharray` 除以线宽再写进去，才是原样。
虚线相位（`stroke-dashoffset`）无法表达，只能丢。

## 阶段 4 结果与校验

本样本的实测值，可作为同类图的量级参照：

| 项 | 数量 |
| --- | --- |
| 色块框 / 卡片框 | 393 |
| 连线 | 1210（源 1458 段描边合并而成） |
| 箭头（源 481 个） | 463 |
| 文字行 | 1297（896 落在框内，401 自由） |
| 虚线边 | 159 |
| 文件 | 810 KB（源 SVG 7.1 MB） |

与原始 SVG 渲染的像素比对：最佳对齐 IoU 0.74，距离变换 > 4px 的残差只剩
若干 5×50 的细条（线宽与抗锯齿差异），**没有大于 150px 的缺失块**。
具体命令与阈值见 `verification.md`。
