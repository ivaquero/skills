# 四向放射式版式规范

版式来源是两张课程概念图（`图片02-1.png`、`图片03.png`）：白底、直角浅灰方框、细灰直线、实心三角箭头指向子节点；中心一个章名节点，主干分居右、左、上、下四个方向，知识点再沿同一方向外推，案例用波浪底文档挂在最外层；连线带小字关系标签。所有颜色、几何、形状以下表为准，不临场调整。

## 几何常量

画布不固定，按内容自适应：先以中心为原点排布，再整体平移到正坐标，四周留 `PAD`。三个半径由常量推导，不写死数值：

```text
D1H = ROOT_W/2 + GAP_ROOT + BRANCH_W/2        中心 → 主干（横向扇区）
D2H = D1H + BRANCH_W/2 + GAP_BRANCH + KID_W/2  主干 → 知识点
D3H = D2H + KID_W/2 + GAP_DOC + DOC_W/2        知识点 → 案例
D1V / D2V / D3V 同理，把宽高换成纵向对应量
```

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `ROOT_W` | 300 | 中心节点宽 |
| `ROOT_H` | 78 | 中心节点高 |
| `BRANCH_W` | 176 | 主干节点宽 |
| `BRANCH_H` | 52 | 主干节点高 |
| `KID_W` | 150 | 知识点节点宽 |
| `KID_H` | 40 | 知识点节点高 |
| `DOC_W` | 160 | 案例文档宽 |
| `DOC_H` | 56 | 案例文档高 |
| `CYL_W` | 152 | 手册圆柱宽 |
| `CYL_H` | 74 | 手册圆柱高 |
| `MAX_KIDS` | 4 | 每个主干的知识点上限 |
| `MAX_BRANCH` | 9 | 主干上限，超出会在 stderr 提示并截断 |
| `GAP_ROOT` | 100 | 中心与主干之间的净空，须容下关系标签 |
| `GAP_BRANCH` | 90 | 主干与知识点之间的净空 |
| `GAP_DOC` | 80 | 知识点与案例之间的净空 |
| `STEP_H` | 62 | 横向扇区内知识点的纵向步距 |
| `STEP_V` | 172 | 纵向扇区内知识点的横向步距 |
| `ROW_GAP` | 36 | 同扇区相邻主干的额外间隔 |
| `PAD` | 60 | 画布四周留白 |
| `CORNER_SHIFT` | 48 | 角落冲突时上下扇区每次外推的距离 |

`MAX_KIDS` 与两个 `STEP` 是耦合的：4 个知识点在 `STEP_H` 下占 3×62+40=226，在 `STEP_V` 下占 3×172+150=666；提高上限必须同步加大步距并重跑重叠校验。

## 扇区分配

主干按讲义顺序轮流落到 `R`（右）、`L`（左）、`T`（上）、`B`（下）四个扇区：第 1 个去右、第 2 个去左、第 3 个去上、第 4 个去下，之后循环。`R`/`L` 里多个主干竖排，知识点沿纵向展开；`T`/`B` 里多个主干横排，知识点沿横向展开。

同一扇区的主干按各自的**占位宽度**依次排布（`max(自身尺寸, 知识点扇面, 案例跨度)`），从中心线向两侧对称摊开，而不是按统一间距等分——统一间距会让没有知识点的圆柱体把邻居顶到角落里。

「OpenCV 官方手册」圆柱体不占主干名额，放进当前最空的扇区（数量相同则按 `B`、`T`、`L`、`R` 优先），只与中心相连，不再挂子节点。

四角是上下扇区与左右扇区的交界，容易互相压住：排布完成后做一轮确定性外推，凡与别的组相交的 `T` / `B` 组，整组沿轴向外移 `CORNER_SHIFT`，直到无相交（最多 120 轮）。外推只动上下扇区，左右扇区位置保持稳定。

## 形状与配色

| 类别 | draw.io 形状 | 填充 / 边框 / 文字 |
| --- | --- | --- |
| 中心（章名） | 直角矩形 | `#F0F0F0` / `#B1B1B1` / `#000000`，14pt |
| 主干 | 直角矩形 | 同上，12pt |
| 核心主干（第 1 个） | 直角矩形 | 同上，文字改红 `#FF0000` |
| 应用主干（识别/检测/应用/实战/实践/搜图/部署） | 直角矩形 | 同上，文字改蓝 `#0000FF` |
| 知识点 | 直角矩形 | 同上，10pt |
| 做法类知识点（方法/规范/流程/步骤/技巧/策略/准则/操作结尾） | 胶囊 `rounded=1;arcSize=50` | 同上，10pt |
| API 类知识点（`cv2.` / `OpenCV` / `NumPy` / `dlib.` / `sklearn.` / `torch.`） | 直角矩形 | `#DAE8FC` / `#6C8EBF` / `#000000`，10pt |
| 案例 | 波浪底文档 `shape=mxgraph.flowchart.document` | `#FFFFFF` / `#BFA9C8` / `#000000`，10pt |
| 官方手册 | 圆柱 `shape=cylinder3` | `#F0F0F0` / `#B1B1B1` / `#000000`，11pt |

正文一律带 `whiteSpace=wrap;html=1;align=center;verticalAlign=middle;fontFamily=Microsoft YaHei;`，不设阴影、不加粗。

## 连线与标签

统一直线，颜色比节点边框深一档，箭头小而实心：

```text
edgeStyle=noneExpr;rounded=0;html=1;strokeColor=#666666;strokeWidth=1;
endArrow=block;endFill=1;endSize=7;startArrow=none;
fontSize=9;fontColor=#333333;labelBackgroundColor=#FFFFFF;
```

| 关系 | 方向（箭头指向） | 标签 | 标签位置 `x` |
| --- | --- | --- | --- |
| 中心 → 主干 | 主干 | `内容包含` | 0.62 |
| 中心 → 官方手册 | 圆柱 | `包含` | 0.62 |
| 主干 → 知识点 | 知识点 | `包含` | 0.58 |
| 案例 → 知识点 | 知识点（案例支持某条做法） | `支持` | 0.45 |

标签位置是相对连线的比例，0 在起点、1 在终点。统一偏向子节点一侧，否则会被中心节点或主干压住；案例连线短，取 0.45 居中偏起点。标签白底只用来让文字盖住线，不改变字号与颜色。

## 完成判据

- 同一份讲义重复生成，除时间戳外字节一致；给固定 `--modified` 时应当完全一致。
- 任意两个有边框节点的矩形重叠对数为 0。
- 最密（9 主干，`09-KNN与SVM`）与最疏（2 主干，`07-模板匹配`）都要目视通过：标签完整、文字不溢出、无遮挡、四角不挤压。
- 中心节点只写章名，不带课程序号、课次或讲义编号。
