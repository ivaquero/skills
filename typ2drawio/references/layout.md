# 中心放射式版式规范

版式来源是一张 1394×688 的课程知识建模图：白底、浅灰节点、细灰直线加实心三角箭头，连线带小字关系标签；中心一个大节点，主干沿圆周放射，知识点再向外放射一层，案例文档挂在最外层。所有颜色、几何、形状以下表为准，不临场调整。

## 几何常量

画布 1800×1400，中心 (900, 700)。主干位于半径 `R1` 的圆周上；知识点从主干沿放射方向外扩 `KID_OUT`、沿切向在 ±`KID_SPAN` 内等距排开；案例文档同理用 `DOC_OUT` / `DOC_SPAN`。

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `PAGE_W` | 1800 | 画布宽度 |
| `PAGE_H` | 1400 | 画布高度 |
| `CX` | 900 | 画布中心横坐标 |
| `CY` | 700 | 画布中心纵坐标 |
| `R1` | 300 | 主干中心半径，须留出中心与主干之间的标签空间 |
| `KID_OUT` | 190 | 知识点相对主干的径向外扩 |
| `KID_SPAN` | 187.5 | 知识点切向半跨度 |
| `DOC_OUT` | 320 | 案例文档相对主干的径向外扩 |
| `DOC_SPAN` | 75 | 案例文档切向半跨度 |
| `CENTER_W` | 260 | 中心节点宽 |
| `CENTER_H` | 70 | 中心节点高 |
| `BRANCH_W` | 150 | 主干节点宽 |
| `BRANCH_H` | 56 | 主干节点高 |
| `KID_W` | 100 | 知识点节点宽 |
| `KID_H` | 46 | 知识点节点高 |
| `DOC_W` | 120 | 案例文档节点宽 |
| `DOC_H` | 56 | 案例文档节点高 |
| `MAX_BRANCH` | 5 | 图形化主干上限，其余进补充组 |
| `MAX_KIDS` | 4 | 每个主干的知识点上限 |

`MAX_KIDS` 与 `KID_SPAN` 是耦合的：4 个知识点在 ±187.5 内间隔 125，大于节点宽 100；把上限提到 5 会让同组节点相切，必须同时加大切向跨度并重跑重叠校验。

## 扇区分配

槽数 = 图形化主干数 + 1。角度从正上方 -90° 起，每隔 `360 / 槽数` 度一个槽，第 1 号槽（右上或正右）固定给「官方手册与资源」圆柱体，其余槽按讲义顺序放内容主干。正下方的主干改用红色胶囊，作为本讲重点标记。

一份讲义最多图形化 `MAX_BRANCH` 个主干；多出来的模块名放进左下角补充组：一个「其余知识模块」标题、最多 3 个竖排窄条，以及一个无边框说明框列出全部模块名，保证信息不丢。

## 形状与配色

| 类别 | draw.io 形状 | 填充 / 边框 / 文字 |
| --- | --- | --- |
| 中心 | 圆角矩形，两行文字 | `#E8EAED` / `#5F5E5A` / `#1A1A1A`，15pt 加粗 |
| 主干 | 直角矩形 | `#F2F2F2` / `#7F7F7F` / `#1A1A1A`，12pt 加粗 |
| 重点主干 | 胶囊（`rounded=1;arcSize=50`） | 同上，文字改 `#D93025` |
| 官方手册 | 圆柱体（`shape=cylinder3`） | 同上，文字改 `#1A73E8` |
| 知识点 | 直角矩形 | 同上，10pt |
| 案例 / 资源 | 波浪底文档（`shape=mxgraph.flowchart.document`） | 同上，10pt |
| 支撑语言 | 绿框矩形 | `#F2F2F2` / `#188038` / `#188038` |
| 补充组 | 小标题 + 竖排窄条 + 无边框说明 | 灰阶 |

竖排窄条用逐字 `<br>` 换行实现，不是旋转文本。所有节点带 `whiteSpace=wrap;html=1;fontFamily=Microsoft YaHei;align=center;verticalAlign=middle;`。

## 连线与标签

统一直线：`edgeStyle=noneExpr;rounded=0;html=1;strokeColor=#7F7F7F;strokeWidth=1;endArrow=block;endFill=1;endSize=8;startArrow=none;`，标签小字 9pt、灰字白底。

| 关系 | 方向 | 标签 |
| --- | --- | --- |
| 中心 → 内容主干 | 向外 | `内容包含1` … `内容包含N` |
| 中心 → 官方手册 | 向外 | `包含` |
| 主干 → 知识点 | 向外 | 首条 `内容包含`，其余空 |
| 案例 → 知识点 | 向内（案例支持知识点） | `支持` |
| 支撑语言 → 中心 | 向内 | `支持` |
| 补充组标题 → 竖排窄条 | 向下 | 首条 `包含`，其余空 |

中心到主干的两类标签必须写 `<mxGeometry x="0.2" relative="1" as="geometry"/>`，把标签沿连线偏向主干。放在默认中点会被中心节点压住，4 槽布局下几乎完全看不见。

## 完成判据

- 同一份讲义重复生成，除时间戳外字节一致；给固定 `--modified` 时应当完全一致。
- 任意两个有边框节点的矩形重叠对数为 0。
- 最密布局（6 扇区）与最疏布局（4 槽）都要目视通过：标签完整、文字不溢出、无遮挡。
