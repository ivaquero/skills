# Typst 讲义解析规则

解析目标是把一讲 `.typ` 变成「主干 / 知识点 / 案例」三层结构，供版式脚本画图。只认标题行，不解析正文、代码块与图片。

## 标题识别

按行匹配 `^\s*(={1,3})\s+(.+?)\s*$`：`=` 是一级（主干）、`==` 是二级（知识点）、`===` 是三级（同样算知识点）。先去掉 Typst 标签（如 `<touying:hidden>`）与多余空白，再判断类型。

处理顺序不能变：

1. 空行或空标题跳过。
2. **命中公式噪声则跳过，但保留当前分组**。Typst 的数学排版会以 `= - 1 / m sum_(...)` 这类形式出现，看起来就是一级标题。若按一级标题处理并清空当前分组，其后的整段二级知识点会全部丢失 —— 实测多讲中招。
3. 一级标题：命中跳过清单则清空当前分组并跳过；否则新建一个分组。
4. 二级、三级标题且当前分组存在：以「示例」「案例」开头的走示例清洗；命中跳过清单则忽略；其余作为知识点。
5. 当前分组不存在时忽略该标题。大多数讲义把「教学目标」放在第一个一级标题之前，自然被忽略。

公式噪声判据：反斜杠、`frac`、`sum_`、`ctext(`、`approx`、`times`、`norm(`、`×`、行首运算符、`log_`、`max_`、`argmax`、比较符、希腊字母与求和号、`P(` / `Q(`、`$`。

跳过清单：

| 层级 | 条目 |
| --- | --- |
| 一级 | 课后作业、教学目标、上节回顾 |
| 二级 | 教学目标、本讲小结、课后作业、课后、上节回顾、这一节在做什么、读结果、读这张表、这一讲要回答的问题、读这组数字 |

## 示例清洗

示例标题形如 `示例 ex27.1_dlib_face_detect_camera·dlib 摄像头检测` 或 `案例 ex13.3 · 定位`。清洗顺序：去 Typst 标签 → 去「示例 / 案例」前缀 → 若含 `·` 取最后一段 → 去 `ex` 加编号的标识符 → 去首尾分隔符 → 若结果不足两字或全为英数符号则丢弃 → 截断到 28 字（不加省略号，避免扫描时把省略号当噪声）。

清洗后的示例同时进入三个位置：所属主干的知识点（补足示例型章节的密度）、所属主干的案例文档、全讲示例清单（供官方手册圆柱体与资源节点使用）。

## 主干整理

- 主干名去掉末尾数字（避免编号型标题重复），重名时追加「（进阶）」。
- 每个主干的知识点 = 该组二级/三级标题去重 + 该组示例去重，最多 `MAX_KIDS` 个；为空时补一条中性资源条目。
- 图形化主干不足 3 个时，用全讲真实示例补一个「本讲实践案例」主干，避免图面过空。
- 超过 `MAX_BRANCH` 的主干名不丢弃，全部写入左下角补充组。

## 编号与文件名

| 输入 | 处理 |
| --- | --- |
| 讲义 | 文件名须为 `vNN-<讲名>.typ`，按 `NN` 升序；`NN` 必须等于它在序列中的位置，否则报错退出 |
| 教案 docx（可选） | 从 `图像处理与识别-<编号>.docx` 之类文件名末尾提取编号，排序后与讲义一一配对 |
| 产物 | `<编号>-<讲名>.drawio`；无 docx 目录时编号取讲义的 `NN` |

编号可含分卷（`02-1`、`02-2`），排序用字符串排序即可，不要把 `02-1` 当数字解析。docx 数量与讲义数量不等时必须报错，不要静默截断或补位。

## 常见失败

- 只扫描一级标题的图会在公式行处断掉，后半讲知识点全空。
- 把示例标题直接当节点文字，会出现 `ex27.1_dlib_face_detect` 这类英文标识符。
- 把「教学目标 / 本讲小结」放进图里，会多出无内容的空模块。
- 生成后必须跑噪声扫描：公式符号、`ex\d`、双下划线、省略号、`#code` / `#figure` 都不该出现在任何 `mxCell` 的 `value` 里。
